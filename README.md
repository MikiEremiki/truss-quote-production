# MiTek Costing & Production Suite v2.0

Инженерно-экономический программный комплекс для обработки выгрузок из расчетного комплекса **MiTek Pamir** (`.xlsm` / `.xlsx`), точного расчета коммерческих предложений (КП), попозиционного управления маржинальностью и подготовки производственных заданий для цеха сборки и распила ферм на МЗП.

---

### Архитектура модулей и слоев

Проект организован в виде модульного монорепозитория:

- **`costing`** — основной пакет приложения:
  - **`costing.core`** — доменные модели, справочники ценовых политик ДревКаркас (`DK_PRICING_CATALOG`), профили клиентов и агентов, модуль пользовательских настроек (`settings.py`, файл `settings.json`);
  - **`costing.data_import`** (псевдоним `importers`) — парсер выгрузок MiTek Pamir, расчет геометрии и 4-сторонней площади заготовок;
  - **`costing.calculator`** — расчетный модуль (прямые затраты на доску/МЗП, прирезка, сборка на прессе, проектирование, антисептирование, накладные расходы);
  - **`costing.quote`** — коммерческие предложения, версионирование, расчет скидок, агентских комиссий (`markup`/`margin`/`discount`), расчет НДС, экспорт в печатные формы/PDF;
  - **`costing.workorders`** — наряды производства, сборочные задания по маркам ферм, расчет потребности в досках 6м по сечениям, 1D Bin Packing оптимизатор раскроя заготовок на хлысты в мм;
  - **`costing.api`** — REST API бэкенд на базе FastAPI (включая эндпоинты администрирования `/api/admin/*`);
- **`web`** — Single Page Application (SPA) веб-интерфейс с боковой навигацией по функциональным блокам (`web/templates/index.html`, `web/templates/admin.html`, `web/static/js/app.js`, `web/static/js/modules/ifc-viewer.js`, `web/static/css/styles.css`);
- **`docs`** — документация, архитектурные решения и регламенты:
  - [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) — архитектурная схема и потоки данных;
  - [`docs/ADR.md`](docs/ADR.md) — реестр принятых архитектурных решений (ADR);
  - [`docs/PRICING_POLICY.md`](docs/PRICING_POLICY.md) — регламент ценообразования и формулы P&L;
  - [`docs/PRODUCTION_GUIDE.md`](docs/PRODUCTION_GUIDE.md) — производственный регламент, карты раскроя и послойный сбор;
  - [`docs/API.md`](docs/API.md) — документация эндпоинтов REST API;
- **`tests`** — автоматизированный набор модульных тестов.

### Архитектура интерфейса (Sidebar & Functional Blocks)

Интерфейс спроектирован по модульному принципу и разделен на 5 функциональных рабочих блоков:
1. **Продажи (Sales):**
   - **Клиентское КП**: коммерческое предложение с попозиционной разбивкой, расчетом скидок, выбором условий поставки и экспортом в печать;
   - **P&L Финансы**: управленческий финансовый отчет, маржинальность, расчет агентских комиссий (`markup`/`margin`/`discount`) и НДС.
2. **Производство (Production):**
   - **Наряды цеха**: сборочные наряды по маркам ферм, расчет потребности в стандартных досках 6м по сечениям, ведомости запрессовки МЗП и спецификации;
   - **Раскрой (мм)**: интерактивные карты 1D-раскроя пиломатериала в хлысты с контролем остатков и ширины пропила;
   - **Пластины МЗП (м²)**: сводная ведомость соединительных пластин по типоразмерам и площадям;
   - **Заготовки**: спецификация деревянных элементов с длинами, сечениями и углами реза.
3. **Внутренние расчеты (Estimates):**
   - **Обзор и Конструктив**: общие геометрические параметры кровли, сводная ведомость конструкций с алиасами типов;
   - **Позиции & Сложность**: настройка коэффициентов сложности, расценок сборки, прирезки и защитной обработки по маркам;
   - **Калькулятор стоимости**: прямые затраты на материалы (доска, МЗП), проектирование, крепеж, логистику и накладные;
   - **Смета руководителя**: детальный внутренний калькуляционный лист себестоимости.
4. **IFC Обзор (3D BIM):**
   - **3D-модель (IFC)**: интерактивный 3D-просмотр геометрии стропильной системы и ферм на базе Three.js / Web-IFC с управлением камерой (вращение, сдвиг, зум).
5. **Настройки (Admin):**
   - **Админка настроек**: сопоставление и сохранение алиасов типов конструкций в `settings.json`.

### Быстрый запуск

1. Дважды кликните по файлу **`start_server.bat`** (или выполните команду `uv run app.py` в терминале).
2. Откройте в браузере: **[http://127.0.0.1:8000](http://127.0.0.1:8000)**.
3. Панель администрирования настроек: **[http://127.0.0.1:8000/admin](http://127.0.0.1:8000/admin)**.
4. Документация Swagger/OpenAPI: **[http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)**.

### REST API

- `GET /api/info` — Информация о версии и программном комплексе.
- `GET /api/sample` — Получение данных и расчетов по тестовому объекту `Богородск 21`.
- `POST /api/upload` — Загрузка и парсинг нового файла `.xlsm` / `.xlsx`.
- `POST /api/costing/calculate` — Расчет себестоимости и прямых затрат.
- `POST /api/positions/calculate` — Расчет параметров и сложности позиций.
- `POST /api/cutting/optimize` — Оптимизация 1D-раскроя пиломатериала.
- `POST /api/financials/calculate` — Расчет P&L, скидок, агентских и НДС.
- `POST /api/calculate` — Комплексный пересчет себестоимости, попозиционных параметров и раскроя.
- `POST /api/quote` — Формирование структурированного коммерческого предложения.
- `POST /api/workorders` — Генерация производственных нарядов для цеха.
- `GET /api/admin/type-aliases` — Получение типов конструкций из файла, справочника вариантов и сохраненных алиасов.
- `PUT /api/admin/type-aliases` — Сохранение сопоставления алиасов типов конструкций в `settings.json`.
